Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Jupyter you can:
 - open a private security issue on given repository (if not enable let us know by email, and we'll enable)
 - send report to security@jupyter.org (new since 2025)
 - send report to security@ipython.org (this email may be sunset in the future)
 

See more information in our [docs](https://jupyter.org/security).
